# World Generator

Programa en Python que genera mapas de alturas (heightmaps) de forma procedural a partir de distintos algoritmos. Ideal para cualquier aplicación donde se requiera crear terrenos 3D.

## Requisitos

- Python 3.x

## Instalación

- Utilizar un entorno virtual (recomendado)
- Instalar las dependencias
```bash
pip install -r .\requirements.txt
```

## Ejecución

Ejecuta el programa principal:

```bash
python app.py
```
